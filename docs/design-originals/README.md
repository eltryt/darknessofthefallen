# Ilustraciones del rediseño

Originales proporcionados por el propietario el 14 de octubre de 2026, conservados sin modificar.
Las versiones web están en `public/assets/art/*.webp` (ImageMagick, calidad 83, sin metadatos). No se han generado ni descargado ilustraciones nuevas.

- castle: castillo; portada.
- war-room: planeando raid; cabecera del roster.
- raid-journey: ir a la raid; cabecera y acceso a raids.
- campfire: acampada; comunidad.
- heroes: 5 heroes; reclutamiento.
- landscape: Fondo 2; acceso a progreso.
- onyxia: ilustración vertical; tarjeta ambiental de Raids. No implica una victoria ni convocatoria real.

Las referencias index, raids y roster guían la composición; no se sirven como fondos ni sustituyen HTML.
